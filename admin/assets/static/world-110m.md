world-110m.json -- the outline the dashboard's map draws.

Source: Natural Earth, 1:110m Cultural Vectors, Admin 0 – Countries
(naturalearthdata.com), which is in the public domain.  Projected to an
equirectangular 1000×500 box (x = (lon+180)/360·1000, y = (90−lat)/180·500)
with one decimal, one SVG-style path string per polygon ring and the
duplicate points dropped; "centroids" maps ISO 3166-1 alpha-2 codes to the
[lon, lat] a country's streams start from (a bounding-box mean per country,
hand-placed for the large or scattered ones).  Regenerated by hand; the
dashboard reads it through /static/world-110m.json.
