package repository

Signed rpm / deb / apk repositories for x86_64 and aarch64. To install, use the guided setup at unmask.sh/install — the directories below are the raw repository tree (browse for exact filenames, sizes, and checksums).

  • rpm/ DNF / YUM repository — RHEL · Alma · Rocky · Fedora (x86_64, aarch64).
  • deb/ APT repository — Debian · Ubuntu (pool/ + signed dists/).
  • apk/ Alpine repository — signed APKINDEX (x86_64, aarch64).
  • releases/ Per-version archive — the packages, static binaries and signed checksums.txt of each release, kept for the newest six (every version is also on GitHub Releases). The repositories above carry only the current version; use this to install or pin an older one — see installing a specific version.
  • testing/ Pre-release builds — not for production. A fix published for confirmation before it is released; the same file is copied into the repositories above once confirmed. Configured by unmask-release and inactive unless asked for by name — see installing a specific version.
  • keys/ GPG + apk signing public keys (for manual verification, shared by both channels).
  • ipgeo/ DB-IP Lite GeoIP mirror (CC BY 4.0) used by unmask install-ipgeo.
  • feed/ Aggregated community-bans bot-IP / JA4 feed.

Verify by hand: RPM-GPG-KEY-unmask (rpm / deb) · unmask.rsa.pub (apk)
