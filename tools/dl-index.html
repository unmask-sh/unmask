package repository

Signed rpm / deb / apk repositories for unmask, for x86_64 and aarch64. Browse the artifacts, grab the signing keys, or mirror the tree for air-gapped installs.

Just want to install? Use the guided setup at unmask.sh/install — it adds the right repo for your distro with GPG verification, no curl | sh. These pages are for direct browsing, manual download, and signature verification.

Add the repository

Each line installs the unmask-release bootstrap package, which drops the repo definition + signing key in place. After that, install unmask unmask-plugin-nginx unmask-web-nginx pulls the rest. For arm64, swap x86_64 → aarch64.

RHEL / Alma / Rocky / Fedora dnf

sudo dnf install -y \
  https://unmask.sh/dl/rpm/x86_64/RPMS/unmask-release-latest.noarch.rpm
browse x86_64 browse aarch64

Debian / Ubuntu apt

wget https://unmask.sh/dl/deb/pool/main/u/unmask/unmask-release_latest_all.deb
sudo apt install -y ./unmask-release_latest_all.deb
browse pool / dists

Alpine apk

wget https://unmask.sh/dl/apk/main/x86_64/unmask-release-latest.apk
sudo apk add --allow-untrusted ./unmask-release-latest.apk
browse x86_64 browse aarch64

Full per-distro walkthrough (CentOS 6/7, EPEL notes, forward-auth vs native): unmask.sh/install.

Signing keys & verification
