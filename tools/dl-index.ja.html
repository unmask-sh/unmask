パッケージリポジトリ

x86_64 と aarch64 向けの署名付き rpm / deb / apk リポジトリです。インストールは unmask.sh/install のガイド付きセットアップから。 以下のディレクトリは生のリポジトリツリーで、正確なファイル名・サイズ・チェックサムを確認できます。

  • rpm/ DNF / YUM リポジトリ — RHEL · Alma · Rocky · Fedora (x86_64, aarch64)
  • deb/ APT リポジトリ — Debian · Ubuntu (pool/ + 署名済 dists/)
  • apk/ Alpine リポジトリ — 署名済 APKINDEX (x86_64, aarch64)
  • keys/ GPG / apk 署名用の公開鍵(手動検証向け)
  • ipgeo/ DB-IP Lite GeoIP ミラー (CC BY 4.0)。unmask install-ipgeo が利用
  • feed/ community-bans の bot IP / JA4 集約フィード

手動で検証する場合: RPM-GPG-KEY-unmask (rpm / deb) · unmask.rsa.pub (apk)
